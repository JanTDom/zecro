# CSS Multi-Column Layouts for Print & Web

## Key Properties

| Property | Values | Description |
|---|---|---|
| `column-count` | `<integer>` | Number of columns |
| `column-width` | `<length>` | Minimum width of each column |
| `columns` | `<count> <width>` | Shorthand |
| `column-gap` | `<length>` | Space between columns (typically 12px–20px) |
| `column-rule` | `<border-style>` | Dividing vertical line between columns |
| `column-span` | `none \| all` | Span across all columns (headlines, full banners) |
| `column-fill` | `auto \| balance` | Balance column heights across the container |
| `break-inside` | `auto \| avoid` | Prevent breaking elements across columns |
| `break-before` | `auto \| column \| page` | Force break to start at new column/page |
| `break-after` | `auto \| avoid` | Keep heading with its next paragraph |
