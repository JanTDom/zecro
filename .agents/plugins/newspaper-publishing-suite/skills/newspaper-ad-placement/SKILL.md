# Newspaper Advertising & Modular Grid Placement

Advertising units in newspapers follow standardized modular sizes and strict placement conventions so they never overwhelm the editorial integrity of the page.

## 1. Standard Modular Ad Units

| Name | Dimensions (Columns × Height) | Placement Rule |
|---|---|---|
| **Skyline / Ribbon** | Full page width (6-col) × 30–45mm | Top bar above or below masthead |
| **Half-Page Horizontal** | Full page width (6-col) × 50% page height | Anchored to bottom edge |
| **Half-Page Vertical** | 3 columns × 100% page height | Anchored to right or left outer edge |
| **Junior Page / Island**| 4 columns × 60% page height | Centered or bottom-right, surrounded by L-shaped copy |
| **Quarter Page (2x2)** | 2 columns × 140mm | Bottom-right corner |
| **Ear Ad (Earbox)** | 1 column × 40mm | Top-left or top-right of the front-page nameplate |
| **Strip Ad** | 6 columns × 35mm | Bottom footer banner |

## 2. The Editorial "Well" Placement Rule

In newspaper layout design:
1. **Ads Anchor to Bottom & Right**: Advertising must always anchor to the bottom and/or right edges of the page.
2. **The "Well" / Inverted Pyramid**: Editorial news copy forms a natural "well" on top and to the left of the ads.
3. **No Floating Ads**: An advertisement must never float in the middle of a text story without grounding to an edge or margin rule.
4. **Clear Separation**: A `0.5pt` border rule and a small uppercase `ADVERTISEMENT` or `OGŁOSZENIE / REKLAMA` disclaimer (6pt sans-serif) is mandatory above every ad.
