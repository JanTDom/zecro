# Newspaper Headline Terminology & Hierarchy

- **Banner / Streamer**: Extends across the top of the entire front page.
- **Hammer / Bark**: Huge primary line (1-3 words) with smaller deck below.
- **Tripod**: Three-part headline consisting of a large left element and two smaller stacked right elements.
- **Kicker / Eyebrow**: Upper teaser line preceding the main head.
- **Deck / Subhead**: Narrative 2-3 line secondary headline.
- **Crosshead / Subhead**: Bold sub-headings breaking up long body text every 3-4 paragraphs.
