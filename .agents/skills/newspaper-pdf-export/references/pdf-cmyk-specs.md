# PDF Print Production & Color Specifications

## Print Rules
- **Color Space**: For offset lithography newsprint, use CMYK (or pure Gray/K channel for black and white news pages).
- **Ink Density (TAC - Total Area Coverage)**: Newsprint has high ink absorption (dot gain 25–30%). Keep total ink coverage under 240%–260% to prevent smearing.
- **Image Resolution**: 200–300 DPI for newsprint halftone reproduction (85–100 lpi screen ruling).
- **Bleed & Trim**: Set 3mm bleed when elements run off the page edge (primarily magazine covers or full-page ads; editorial newsprint typically has 10–12mm unprinted gripper margin).
