# Otwarte pozycje

- Widok flatplanu ma persystencję wydania, katalog modułów, przeciąganie
  reklam na strony, import CSV, status tentative oraz blok shortów.
- Etykiety advertorial są emitowane w SVG/HTML/IDML i sprawdzane przez
  preflight. Ostateczna decyzja o typografii etykiety pozostaje po stronie
  redakcji, ale brak etykiety jest już błędem blokującym.
- Rzeczywisty model preferencji dyrektora wymaga par A/B z produkcji; obecny
  krytyk heurystyczny i istniejący taste loop pozostają aktywne.
- Brak klucza AI uruchamia bezpieczny placeholder deterministic-local zgodnie
  z provider registry.
